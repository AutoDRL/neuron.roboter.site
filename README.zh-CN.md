# Neuron

**Neuron** 是一个从零开始探索全双工、多模态通用模型的开放研究项目。

项目关注实时多模态感知与生成、学习式信息压缩、可复用表示，以及长期记忆机制。

> **当前状态：** 仓库已包含一个初始字节级文本模型基线，以及基础训练、验证和导出流程。这些是工程起点，并非最终的全双工多模态架构。

## 研究目标

- **全双工交互：** 研究感知与生成并行进行的机制，而非严格轮流的单轮对话流程。
- **多模态表示：** 探索文本、音频、图像及其他信号的共享表示与模态专属表示。
- **学习式信息压缩：** 研究模型如何从底层输入中学习紧凑、可复用的信息单元。
- **记忆与整合：** 研究信息的长期保留、组合和重复利用机制。
- **高效训练与推理：** 优先考虑显存、吞吐量和不同硬件预算下的部署可行性。

## 初始工程目标

- Python 3.10+
- PyTorch 2.0+
- 尽可能采用可检查、可控的原生实现
- 模块化训练、验证和导出入口
- 面向不同硬件预算设计配置，并重视单 GPU 开发路径

初始研究目标包含一个 3B 参数级模型，但具体规模取决于可行性评估、数据条件和算力资助。这是目标，不是已完成成果。

## 快速开始

安装项目及测试依赖：

```bash
python -m pip install -e ".[dev]"
```

准备 UTF-8 文本语料后，运行小型字节级基线：

```bash
python trainer.py --config configs/byte_lm_tiny.json --data /path/to/corpus.txt
```

验证、导出、测试和已知限制请阅读[基线使用说明](docs/byte-baseline.md)。

## 仓库结构

```text
.
├── configs/       # 模型与实验配置
├── dataset/       # 数据准备与输入流水线
├── docs/          # 架构、研究记录与路线图
├── modules/       # 模型模块与优化算子
├── solvers/       # 优化器、损失函数及训练组件
├── toolkit/       # 通用工具、文件读写与解析
├── trainer.py     # 统一训练入口
├── valider.py     # 统一验证入口
└── exports.py     # 模型导出入口
```

## 开放协作

Neuron 计划以透明方式面向全球开发者开放协作。贡献应尽量包含可复现实验、清晰文档，并严格区分已验证结果与未来计划。

目前仓库尚未添加许可证。在明确选择并发布许可证之前，请勿默认代码已经授予复用许可。
